# Villa Palmarin — montages vidéo (Mau-rent Houses)

4 versions, sans musique (bruitages légers), identité Mau-rent Houses (logo, Abril Fatface + Epilogue, bleu marine / corail / pêche) :
- `Villa-Palmarin_Instagram-9x16_avec-reservation.mp4` / `..._sans-reservation.mp4` (1080x1920 — Reels, Stories, TikTok)
- `Villa-Palmarin_Facebook-4x5_avec-reservation.mp4` / `..._sans-reservation.mp4` (1080x1350 — fil Facebook)
- `*_bruitages.wav` : piste de bruitages seule de chaque version
- `photos-retouchees/` : 15 photos uniques retouchées, numérotées dans l'ordre (couverture = photo 1)
- `scripts/` : `VILLA=palmarin FMT=9x16|4x5 CTA=1|0 BRAND_DIR=../lyla-villa-montage/brand python3 scripts/montage.py photos-retouchees sortie.mp4 full`
